# 이 문서의 목적
이 문서는 AWS에서 Kubernetes를 운영하시는 고객사의 교육을 위한 보조 자료입니다.

## 모듈 구성

| 디렉토리 | 주제 |
|----------|------|
| `introduction/` | 환경 설정, 시작하기, Helm, Kustomize |
| `fundamentals/` | 서비스 노출, Fargate, Graviton, 관리형 노드 그룹, 스토리지 |
| `networking/` | EKS Hybrid Nodes, 네트워크 정책 |
| `security/` | IRSA, Pod Identity, Secrets, Secrets Manager |
| `observability/` | 로깅, Container Insights, OpenSearch |
| `autoscaling/` | Cluster Autoscaler, HPA, Karpenter, KEDA |
| `automode/` | EKS Auto Mode |
| `automation/` | GitOps |
| `docker-basic/` | Docker 기초 |
